# Team Conventions

## Branching
- `main`: production-ready code
- `develop`: integration branch
- `feature/*`: new features
- `fix/*`: bug fixes

## Commits
Follow conventional commits:
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `chore:` maintenance

## Code Review
- Minimum 1 approval required
- All tests must pass
- No merge conflicts
